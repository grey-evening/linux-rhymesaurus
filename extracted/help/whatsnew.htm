August 1, 2008

Version 2.0.1

 

·Improved performance of Rhyme searches and Sounds Like searches
·Made automatic searching optional. With automatic searching turned on, you don't need to click the Search button every time you make a change.
·In Sounds Like searches, combined "Soundex" and "Metaphone" results into a single list.
·In WordSurf added "All" to the Word Type list, to combine all results (noun, verb, adverb, and adjective) into a single result.

 

 

July 1, 2008

Version 2.0

 

·Windows Vista compatibility
·Significantly smaller installation size
·Tabbed interface
·Idioms/phrases/proverbs in perfect/normative rhymes
·A scratch pad for saving notes
·Upgraded WordSurf from WordNet 1.6 to WordNet 3.0
·Fixed a bug in the "Check for Newer Version" feature
·New license key registration system

 

July 12, 2003

Version 1.4

 

·Added highlighting based on word frequency.
·Fixed issue where program had trouble opening database on some systems.

 

December 1, 2000

Version 1.3

 

·Added new rhyme types: Light, Back, Consonance, Double Consonance, Full Assonance, Sight, Half-double, Amphisbaenic, and Elided.
·Changed "Consonance" to "Full Consonance".
·Added a new Pattern Matching Tool.

 

July 5, 2000

Version 1.2

 

·Added new rhyme types: Assonance, Assonance & End, Begins With, EndsWith, and Contains.
·Increased speed of rhyme searches.
·Added all of WordSurf to history, so even changing word type or relationship type adds a history entry.
·Clear status bar text when clearing history.
·Changed history toolbar caption from "Toolbar" to "History".
·Program now correctly removes caption from Clear History button.
·Improved Sounds Like to find words even if they aren't in the pronouncing dictionary.
·Added icons to the Help menu.
·Changed "Matching Consonants" to "Consonance".
·Fixed a minor bug in Consonance.
