To use the rhyming dictionary, select Rhyme in the Search/Link Action area. Then select the type of rhyme search you wish to conduct. You can limit rhyming dictionary, Sounds Like, and Pattern Matching search results to common words by checking the box labeled "Exclude words not in dictionary."
