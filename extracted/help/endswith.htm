Ends With

The Ends With feature of the rhyming dictionary shows you one of two things:

 

1.        If the search text is found in the Rhymesaurus pronouncing dictionary, as a valid word, the program will display all words that end with the same sounds.  For example, if you enter "ray", Rhymesaurus will display all words that begin with a consonant r sound followed by a long a sound, including "gray," "entree," "vertibrae," etc.

 

2.                If the search text is not found in the pronouncing dictionary, the program will display all words that end with the same letters.  For example, if you enter "tion", Rhymesaurus will display all words that end with these letters, including "action," "question," etc.
