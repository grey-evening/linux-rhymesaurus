Contains

The Contains feature of the rhyming dictionary shows you one of two things:

 

1.        If the search text is found in the Rhymesaurus pronouncing dictionary, as a valid word, the program will display all words that contain the same sounds.  For example, if you enter "ray", Rhymesaurus will display all words that begin with a consonant r sound followed by a long a sound, including "rain," "brain," "gravy," etc.

 

2.        If the search text is not found in the pronouncing dictionary, the program will display all words that contain the same letters.  For example, if you enter "cak", Rhymesaurus will display all words that contain this letter pattern, including "cake," "pancake," "shortcake," etc.

 

Note:                Contains rhyme-type searches can be very slow, since the program must do a full text comparison against every word in the dictionary.
